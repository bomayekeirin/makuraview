# まくらびゅ / makuraview

**枕崎市網羅型ポータルサイト**

- 本番ドメイン（予定）: `makuraview.net`
- Instagram: `@makuraview`

---

## これは何のプロトタイプか

「ホーム（カテゴリ分岐）→ 各カテゴリ → 店舗詳細」の流れを実際に触って確かめるための構成。
**58軒・68ページ**が自動生成される。

| 画面 | パス | 状態 |
|---|---|---|
| ホーム（浮きが漂う分岐画面） | `/` | 動く |
| 食べる | `/eat/` | 動く（31軒） |
| **飲む** | `/drink/` | **動く（30軒／料金比較・はしご酒つき）** |
| 出かける・美容・暮らし・はたらく | `/go/` `/beauty/` `/life/` `/work/` | 準備中ページ（行き止まりにしない） |
| 店舗詳細 | `/shop/{slug}/` | 動く（58ページ自動生成） |
| お店を教える | `/entry/` | 動く |
| まちがいを教える | `/contact/` | 動く |
| 404 | `/404` | 動く |

### 実装済みの仕掛け
- **絞り込みが実際に動く**（種類チップ＋「今日の営業日だけ」トグル）
- **ページ遷移で白飛びしない**（全ページ共通。ホームだけ凝っている状態を避ける）
- **料金の横並び**（`/drink/`）── ネット上のどこにも存在しない一覧
- **同じ建物の店**（折口町92、95-1、港町128、CoCoハウス、三愛ビル）
- **不定休の警告**（定休日データだけでは足りない店に出す）
- **予約手段の明示**（DM不可の店にDMを推さない）

## 設計上の約束（変更する前に読むこと）

### 1. 店舗ページの実体は `/shop/{slug}/` に1つだけ
カテゴリごとに別URLを作らない。PVが分散すると「この店が何回見られたか」が集計できなくなり、
店舗向けの実績レポートが成立しなくなる。
重複掲載は `categories` 配列で表現し、見た目のトーンは `primary` の色で切り替える。

### 2. slug は不変
一度公開したら変えない。変える場合は必ず旧URLからリダイレクトを残す。
連番は使わない（`/shop/001/` のような形にすると途中に店を挿入できない）。

### 3. ページは手で作らない
`src/data/shops.ts` に1行足せば `/shop/{slug}/` が自動で生えて、一覧にも載る。
100軒でも1000軒でも運用の手間は変わらない。

### 4. 閉店した店を削除しない
`status: "closed"` にしてページは残す。検索から来た人が404に当たらないようにする。

### 5. `data-track` 属性で計測する
電話・地図・Instagram のタップは `data-track` と `data-shop` を付けるだけ。
拾うのは1箇所（イベント委譲）。各所にJSを書くと必ず抜けが出る。

```html
<a href="tel:0993720357" data-track="tap_tel" data-shop="daitoku">
```

**リリース時点で仕込まないと、後から遡って取得できない。**

## ★noindex について

開発中は検索エンジンにインデックスさせない設定になっている。

- `.env` の `PUBLIC_ALLOW_INDEX=false`
- `public/robots.txt` で全面 Disallow

**独自ドメインへ移行するときに、必ず両方を解除すること。**
解除を忘れると永久に検索に出ない。リリース手順の一番上に置くこと。

## デザインの考え方

出発点は**枕崎漁港に浮かぶ「浮き（ブイ）」**。

- 背景は夜明け前の海。白は泡。
- カテゴリの6色は、実際の漁具の配色から取っている（原色に近いが、海の紺に沈めると落ち着く）
- ホームの浮きは Matter.js の物理演算。指で掴んで放り投げられる
- 見出しは丸ゴシック（Zen Maru Gothic）。「まくらびゅ」のやわらかさに合わせた
- 数字は等幅（Roboto Mono）。営業時間と電話番号が揃う

### ★文字の太さ（ここが読み心地を決めている）

**本文の基準を 400 ではなく 500 に置いている。**

日本語は 400（Regular）だと画面上でスカスカに見える。
500（Medium）にすると字の黒みが増して、同じ書体でも読み心地がまるで変わる。
「普通のフォントなのに気持ちいい」サイトの正体は、たいていここ。

```css
--w-body: 500;    /* 本文の基準 */
--w-strong: 700;  /* 強調 */
--w-head: 700;    /* 見出し */
--w-hero: 900;    /* ロゴ */
--w-faint: 500;   /* 補足も 400 に落とさない。薄さは色で作る */
```

**補足テキストを 400 に落とさない**のがポイント。
弱く見せたいときは太さではなく `color` と `opacity` で調整する。
太さを落とすと、画面全体がぼやけた印象になる。

### 動きを止める配慮
- `prefers-reduced-motion` を尊重し、物理演算を起動しない
- そのときは CSS の並びのまま使える（JSが落ちても浮きは並ぶ）
- タップ領域は最小 56px

## 掲載データの扱い

**現在の店舗データは全件 `status: "draft"` 相当（未許諾）。**

調査段階で外部サービスから収集した情報を下敷きにしているため、そのままでは公開できない。
公開するのは、店舗本人に確認・許諾を取ったものだけ。
紹介文は他サイトの文言を使わず、自前の取材・要約に置き換える。
